HTML (Hypertext Markup Language) was invented by British physicist and computer scientist Tim Berners-Lee in late 1990 while working at CERN. He created it alongside the first web browser and server software to help researchers easily share and format documents across incompatible computer systems.

Key Milestones in the Creation of HTML

  • 1989: Berners-Lee wrote a formal memo proposing an internet-based hypertext system.
  • 1990: He specified the code structure for HTML and built the very first web browser editor on a NeXT computer workstation.
  • 1991: The first publicly available documentation of HTML, a document titled "HTML Tags," was shared on the internet. This initial design consisted of just 18 elements (such as headings, paragraphs, and lists) heavily based on SGML, an existing documentation format used at CERN.
  • 1993: HTML 1.0 was officially published as a standard for web developers.
